Полная инструкция на GitHub ↗
Терминал
git clone https://github.com/megamen32/agent-herder.git
cd agent-herder
npm ci
npm run build
AGENT_HERDER_WEB_PORT=18787 npm start

  1. 1
    Откройте веб-интерфейс

    http://127.0.0.1:18787/ на машине, где запущен Agent Herder.

  2. 2
    Добавьте сервер в MCP-клиент

    Streamable HTTP: http://127.0.0.1:18787/mcp. Клиенты подключаются к одному работающему экземпляру.

  3. 3
    Подключите свою среду

    Запустите coding-агент и настройте его адаптер. Для OpenCode сначала нужен opencode serve.

Перед стартом

Несколько
важных деталей.

Agent Herder заменяет Codex или Claude Code?+

Он объединяет управление их сессиями. Агент, его модель и привычная среда остаются вашими; Agent Herder добавляет наблюдение, переписку и координацию.

Можно работать с одним агентом?+

Да. Подключите только используемую среду. Остальные адаптеры можно отключить в конфигурации.

Что нужно для подключения?+

Установленная и авторизованная среда coding-агента, работающий Agent Herder и настройка соответствующего адаптера. Возможности управления различаются между средами — они перечислены в документации.

Нужен ли MCP каждому агенту?+

Для получения сообщения Agent Herder использует подключение к среде целевого агента. MCP на стороне агента нужен, когда он сам отправляет сообщения или управляет заметками.

Это бесплатный проект?+

Исходный код Agent Herder открыт под MIT. Вы используете собственную инфраструктуру; расходы на модели и подписки coding-агентов зависят от ваших провайдеров.
