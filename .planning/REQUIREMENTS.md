# Requirements: Agent Herder

**Defined:** 2026-10-12 (brownfield recovery)
**Core Value:** Доводить работу до результата в исходной нативной сессии.

## v1 Requirements

### Automation

- [x] **AUTO-01**: Пользователь отдельно настраивает автопилот и автопродолжение каждой поддерживаемой среды.
- [x] **AUTO-02**: Автокомпакт требует одновременно настраиваемые минимумы контекста и человеческих сообщений, по умолчанию 35% и пять.
- [x] **AUTO-03**: Сжатие сохраняет ID/историю и завершает работу перед концом настроенной оценки окна кэша, не мешая активному ответу.
- [ ] **AUTO-04**: Незавершённые сессии за 48 часов действительно доведены до результата либо имеют конкретный требующий человека блокер.

### Interface

- [x] **UI-01**: Общая навигация находится слева, заголовок чата показывает текущую сессию.
- [x] **UI-02**: Модель, изображение, очередь и Send Now работают через нативную сессию.
- [ ] **UI-03**: Независимые пользователи браузера подтверждают читаемую форму новой сессии без перекрытия и знают назначение кнопок.

### Fleet

- [ ] **MAC-01**: Публичный кабинет с обычным SSO показывает Mac доступным устойчиво и открывает его реальные сессии.
- [ ] **MAC-02**: Наблюдатель не останавливает здоровый агент из-за дорогой проверки; сохраняет проверку владельца и конечные бюджеты.
