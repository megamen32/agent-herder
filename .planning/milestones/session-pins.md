# Следующий майлстоун: закрепления и компактные сведения о сессиях

Статус: UI реализован, опубликован и принят на настоящем сайте 13.10.2026.

## Результат для пользователя

- Закрепить или открепить любую доступную сессию в левом списке.
- Закреплённые сессии находятся сверху и сохраняют закрепление после перезагрузки.
- Под названием — одна небольшая приглушённая строка, например `Codex · 100`
  или `ZCode · M1`; без дополнительных широких карточек.
- На десктопе при наведении и клавиатурном фокусе показывается компактная
  подсказка: полное название, среда, машина, путь проекта (CWD), модель,
  состояние и последнее обновление, если эти данные подтверждены.

## Критерии приёмки

- [x] PIN-01: личное закрепление не запускает, не останавливает и не продолжает
  сессию; отличается от автоматического runtime pinActiveSessions.
- [x] PIN-02: ключ закрепления учитывает машину, среду и нативный ID; одинаковые
  ID разных узлов не смешиваются. В поиске/фильтрах нет двойных строк.
- [x] META-01: компактная строка среды и машины читается на десктопе и мобильном
  экране; длинное название не вытесняет её и не увеличивает блок до большой карточки.
- [x] META-02: подсказка не перекрывает действие закрепления и не обрезается
  боковой панелью. Наведение и клавиатурный фокус дают одинаковые сведения.
- [x] META-03: текущий подтверждённый CWD отличается от каталога запуска.
  Неизвестные сервер, модель или путь честно обозначаются; сведения не выдумываются.
- [x] META-04: реальный сайт проверен на десктопе и мобильном экране через
  managed browser на44/88; нативные сообщения не отправляются для проверки.

## Границы

Текущая поставка реализует личные браузерные закрепления и компактный context. Без нового планировщика,
реестра машин или изменений выбранных моделей и авторизации.
