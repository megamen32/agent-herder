# Проверка автоматизации и интерфейса — 11 октября 2026

## Результат

В Codex и ZCode доступны независимые настройки автопродолжения и автопилота:
общие настройки открываются из меню чата, исключения для выбранного чата — из
«Настроек сессии». Автопродолжение восстанавливает прерванную работу в исходной
нативной сессии; автопилот оценивает незавершённую задачу и продолжает её.
В других средах интерфейс показывает поддерживаемые возможности и объясняет
недоступность восстановления после сбоя.

После сохранения и перезагрузки страницы подтверждена текущая политика:

- автопродолжение включено для Codex и ZCode; восстановление после ошибки,
  разрыва соединения и контроль зависания включены;
- общий автопилот включён только для ZCode; Codex, Claude Code, OpenCode и Hermes
  не выбраны;
- окно поиска незавершённой работы — 48 часов;
- модель оценщика — `glm-5.3-flash`, прямой Coding Plan endpoint
  `https://api.z.ai/api/coding/paas/v4`;
- ключ читается процессом из `/home/roomhacker/agents-projects/zai_key`;
  значение ключа в отчёт и исходники не копировалось.

Существующие исключения отдельных сессий и явные остановки человеком сохранены.
Этот отчёт подтверждает настройки и исправленный интерфейс. Он **не утверждает**,
что все задачи всех чатов за 48 часов уже завершены, и не заменяет отдельный
нативный аварийный canary восстановления сессии.

## Независимая фокус-группа

Три AI-участника имитировали новых пользователей. Они ориентировались только
на интерфейс через Agent Browser: без исходников, API и журналов. После
исследования каждый объяснил ожидаемое действие видимых кнопок. Замечания
обрабатывались по отдельности, без требования согласия большинства.

| Участник | Поверхность | Заключительная проверка |
| --- | --- | --- |
| Новый пользователь настольного Codex/ZCode | 1024 px; инспектор, общие и локальные настройки, клавиатура | PASS; Escape возвращает фокус в видимое меню, Tab продолжает навигацию |
| Пользователь мобильного ZCode | 390 × 844; меню, модели, сохранение, возврат | PASS; оценка понятности 9/10 |
| Пользователь OpenCode и истории | 1440 × 1000; поддержка возможностей, квота, визуализация | Основные исправления PASS; интерфейс и история 8/10; последний найденный счётчик исправлен и дополнительно проверен root |

Участники не запускали задачи, не прерывали чужие сессии и не меняли рабочую
политику. Root отдельно сохранил неизменённые настройки автопилота через UI,
увидел «Настройки сохранены», перезагрузил страницу и проверил их повторно.

## Проверки и границы доказательства

| Проверка | Категория | Что обнаруживает | Ожидаемое / максимальное время | Результат |
| --- | --- | --- | --- | --- |
| Шесть профильных файлов Vitest, один worker | Fast unit | Регрессии элементов UI, политики запуска, выбора сессии, квоты и реального скрипта истории | 3 / 30 с | 63/63, 2.09 с на окончательном коде |
| TypeScript и production Vite build | Release build | Ошибки типов и сборки доставляемых ресурсов | 20 / 140 с | 17.25 с; advisory предупреждение о размере bundle |
| Независимые участники Agent Browser | Focused UI acceptance | Непонятные действия, мобильная компоновка, клавиатура, история и квота | Ручные ограниченные проходы, вне обычного автоматического release-run | Результаты выше |
| Root: Save, reload, Escape, OpenCode inspector, история | Focused live UI acceptance | Потерю сохранения/фокуса и оставшийся счётчик карточки | Один короткий проход | PASS |

Обычный автоматический release-run укладывается в 180 секунд. Браузерные
проверки проводились на реально работающем Herder; все принадлежащие этой
проверке браузерные сессии закрыты. Скриншоты без ключей сохранены локально в
`.tmp/automation-focus-group-2026-10-11/` (ignored), включая root-сохранение
автопилота и два соседних момента истории.

В процессе устранено ограничение управляемого Codex runner: TasksMax 1536 и
CPUQuota 400%, после измерения свободной памяти, отсутствия OOM и давления
предыдущего лимита. Настройки доставлены через канонический systemd control
plane и репозиторий ServersAdministartion, без перезапуска нативного Codex.
Сгенерированные read-only файлы `dist/web` получали owner-write только на время
стандартной сборки; исходные режимы восстановлены в finally.

Изменения интерфейса и проверки опубликованы в `main` Agent Herder, runtime
пересобран и перезапущен. Чужие изменения watchdog Mac и инфраструктурные WIP
сохранены и не включались в коммиты этой задачи.
