В нативной истории Codex сообщения пользователя теперь выровнены вправо, результат инструмента выделен полосой, а у каждого сообщения виден автор. На телефоне второстепенные разделы нижней панели доступны прокруткой или через «Команды». После первого сравнения вкладки настроек на узком экране перенесены в два ряда, а поле названия подключения отделено от кнопки создания токена.
