# Принципы: изоляция продуктов и доступ владельца к настройкам

> **ИСТОЧНИК ИСТИНЫ.** Этот файл — **рабочая запись решений**, а не продуктовый контракт.
> Канон — продуктовый контракт в этом же репозитории: `docs/ownership-and-settings.md`
> (ветка `main`). Он оформлен по этим же решениям и помечает каждое положение
> (Действует / Решение / Цель / Требование / Критерий / Открыто). **Где формулировки расходятся —
> канон это `docs/ownership-and-settings.md`, а не этот файл.** Этот файл хранится как
> исходный материал и не должен читаться как второй контракт.

Принято владельцем 22.10.2026. Действует для всех продуктов контура
(agent-herder, Notice Place, OmniRoute, TGC, ATV, флот-ноды) без исключений.

## 1. Продукты изолированы

- У каждого продукта — **свой** файл окружения и своя зона конфигурации.
  Общий файл окружения, названный по чужому продукту, запрещён.
- Каталог `~/.config/agent-herder/` — только agent-herder. Каталог
  `/etc/notification-center.env` и остальные `/etc/*.env` — только свой продукт.
- Историческая ошибка, исправленная 22.10: юнит `agent-herder.service` читал
  `~/.config/agent-herder/noticeplace.env`. Разделено: у herder теперь свой
  `~/.config/agent-herder/herder.env`, ссылка в юните переключена
  (бэкап юнита: `agent-herder.service.bak-isolation-*`).
- Общие **значения** допустимы (секрет между двумя продуктами — это API-ключ),
  но каждая копия секрета живёт в своём продукте, в своём файле, под своим ключом.
- Код чужого продукта не патчится. Требования к чужому продукту оформляются
  как требование (что именно должен делать центр), а не как правка его кода.

## 2. Все настройки и токены — владельцу с веб-формы

- Владелец должен видеть и менять **все** настройки контура из веб-панели,
  без ssh и без правки файлов на сервере: переменные окружения продукта,
  конфигурация fleet-нод, политика запуска, маршруты и модели, секреты.
- Секреты в форме — **write-only**: значение записывается, но никогда не
  возвращается в ответ (только признак «задан / не задан» и отпечаток-хэш).
  Маскирование, аудит каждой записи, откат к предыдущему значению.
- Форма не должна быть единственным носителем секрета: файлы окружения
  остаются источником для сервисов, форма — способ управления ими.
- Доступ к форме — владелец (loopback + SSO), как у панели herder.

## 3. Что это меняет в контуре

- Любая настройка, до которой раньше нужно было доходить по ssh, переезжает
  в форму: это делает её наблюдаемой и откатываемой без правки прод-хоста.
- Изоляция проверяется: у каждого продукта свой набор файлов окружения,
  пересечений нет.
