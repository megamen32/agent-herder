# Текущее состояние Agent Herder

Сверка 28 ноября 2026 года.

Центральный Herder на сервере 100 владеет публичным MCP, привязками сессий, журналом операций и квитанциями. На удалённых хостах работают нативные приложения и исполнители. Новый удалённый экземпляр подключается через профиль центрального владельца.

| Рабочий путь | Подтверждённый результат |
| --- | --- |
| 100 → Codex на 44 | После остановки местной службы Fleet центр отправил сообщение и прочитал ответ в той же сессии. |
| 100 → Codex на 88 | Установлена конфигурация с девятью профилями. Центр создал выделенную сессию, выполнил отдельную доставку и прочитал ответ и нативную квитанцию. |
| 100 → Codex на Mac M1 | Центр прочитал историю зарегистрированной сессии после отключения местной службы Fleet. |
| Notice Place → 100 → OpenCode | Рабочий HTTP-фасад отправил сообщение через центральное ядро. По исходному ключу получена квитанция доставки, затем прочитан ответ ассистента на это сообщение. |

В ядре на Rust находятся журнал, привязки, квитанции и нативный путь OpenCode. Центральный планировщик и часть адаптеров ещё работают на TypeScript. План переноса должен учитывать установленные процессы и их потребителей.

Установленная команда восстановления принимает только центральный узел. Выбор 44-го со старым планом отклонён до открытия журнала. На 44 остаётся отдельная ошибка получения списка инструментов дочернего MCP. При возобновлении сверяй эти пункты с квитанциями соответствующей выкладки.

При потере подтверждения проверь исходный ключ, журнал и состояние исполнителя. Если эффект подтверждён, верни исходную квитанцию. Если эффект отсутствует, повтори запрос через штатный механизм идемпотентности. UNKNOWN не является конечным исходом операции.
