## Что исправлено

- Явная привязка Vibe к выбранному хосту, namespace, relay и browser session. Отказ при несовпадении владельца и отсутствие неявного выбора другого соединения.
- Восстановление Z.ai draft handle из подтверждённого хранилища аккаунта в новом процессе.
- Отдельное наблюдение за принадлежащим тесту диалогом, сохранение UNKNOWN-квитанций и отсутствие повторной отправки после неопределённого результата.
- Проверка точного сочетания host, harness, native session ID, runtime instance и project в строке и деталях интерфейса.
- Передача явной модели ZCode через профиль запуска и проверка реально выбранного reasoning mode.
- Отдельный браузер CI с постоянным QA-профилем, парным перезапуском browser/relay и проверкой нового поколения процесса.
- Исправления переносимости тестовых временных каталогов на macOS. Обе ошибки воспроизведены на Linux через принадлежащий тесту symlink: 3 ошибки Python и 7 ошибок native worker, затем успешные проходы после исправления.
