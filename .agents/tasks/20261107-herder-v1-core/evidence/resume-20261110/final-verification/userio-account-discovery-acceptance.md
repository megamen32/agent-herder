# Приёмка обнаружения аккаунта ChatGPT

В загруженном расширении 0.9.29 строка аккаунта ChatGPT и флажок назначения UserIO видны в настройках. После одного явного выбора назначения driver прочитал 10 сообщений и подтвердил эффект для legacy-default. Независимый UserIO API подтвердил совпадение 10 из 10. Снимок частичный; полнота всей истории не подтверждена. Данная приёмка относится только к обнаружению и привязке аккаунта.
