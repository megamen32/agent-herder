# Фактический результат 10 ноября

Установлен Rust entry Herder с прежними TS/AHAP адаптерами. Развитие отдельных Rust native adapters не является выбранным путём V1. Обычные CLI экземпляры codex-local, codex-44, opencode-noticeplace-local доступны через один entry. Принятые ранее remote44, child→parent wake и NoticePlace canary не повторялись.

UserIO extension 0.9.29 опубликован в universal-userio main (3db38e788df5d1a8be1ba9c306c9abf67f53a897) и установлен на сервере; в Chrome Mac Mini оба профиля Default и Carevio подтвердили загруженную версию через обычное окно расширений. Backend сохраняет 19 аккаунтов, конфигурацию frontend/voice и отвечает исправно. ZIP SHA256: 1081ca717b4ed8c5b9a288ffe4abb13eabc930349284041f5026cd4b9b5bfb8e.

На настоящем Carevio проверена цепочка: подтверждённая identity ChatGPT → непривязанная строка аккаунта → явный checkbox назначения в настройках → Herder driver → тот же снимок UserIO. Driver получил список из 20 разговоров и 10 сообщений точно выбранного существующего разговора. Независимый API UserIO подтвердил все 10 native message IDs. Обычный MCP SDK с подготовленным Rust профилем зарегистрировал этот разговор и прочитал те же 10 сообщений. session_ref: session:c678f986d231c56992a17b8966dd1397. Полнота истории false/partial; полного экспорта этим не доказано. Сообщений модели и новых разговоров для этой проверки не создавалось.

Доказательства: final-verification/browser-core-read-029.json, userio-native-readback-029.json, userio-029-live-acceptance.json, mac-carevio-loaded029.log, mac-default-loaded029.log, userio-029-receipt.md. Два назначения и изоляция A→Work+Personal/B→Personal, отказ чужой привязке и сохранение состояния проверены отдельным настоящим Chromium с тестовыми endpoint; это fixture, а не второй реальный аккаунт.

Проверенный browser profile установлен в оба общих selector под lease fence95. Три CLI profile сохранены; четвёртый — chatgpt-userio-vk-browser. GPTAdmin child AgentHerder штатно перезапущен под fence96, смена PID подтверждена. Подключённый MCP обнаруживает четыре экземпляра и возвращает context зарегистрированного разговора. Обычный SDK через установленный selector прочитал 10/10 тех же native message IDs. Это установленный маршрут чтения; полнота истории остаётся partial.

У длинного connected session(messages) остаётся отдельная проблема GPTAdmin: операция принята в background job, но receipt недоступен вызывающему из-за несовпадения caller/profile. Обычный installed SDK вернул данные; connected background receipt не получен. Исходные job IDs сохранены в final-verification/public-browser-read-proof.json, новые запросы для обхода очереди не повторяются.

Исправление ручных отправок опубликовано в main как 2388ea932f7f9a508e35a3b9caa9aa926ac5d6b3 и постоянно установлено штатным rollout под lease fence98. Явное поручение человека с серверным timestamp проходит только локальный below_reserve; автоматический origin остаётся заблокирован, отказы провайдера и HumanStop сохраняются. Одна разрешённая отправка в текущий ход NoticePlace получила native admitted=true. Установленный модуль отдельно проверен fixture: ручная отправка допущена, автоматическая отклонена до native write. Служба active, PID3616632; конфигурация вне revision сохранена, lease освобождён. Source56/56 и tsc PASS; доказательства в quota-human12/installed-receipt.json, red.log и green.log.

Полный V1 пока не принят: новый extension transport требует завершить native создание/первую отправку/архивирование ChatGPT, затем Z.ai и пятисредовую CI приёмку; completeness и проекты проверяются отдельно. Source slice ChatGPT выполняет Terra в изолированных worktrees. Vibe/CDP сохранены как experimental/unmaintained и исключены из default browser profiles. Менеджер Chrome Extension MCP разрабатывается в отдельной полной сессии 01a1c600-12bf-7202-9686-fd2de0903386; её controlled mode не доказывает управление обычным профилем или регистрацию в GPTAdmin.

В очередь добавлен SESSIONREPLIES13: без дополнительных аргументов отправитель получает ранний фактический текст сессии и поздний итоговый ответ; expect_reply=false отключает оба и напоминания. При отсутствии итогового ответа существующий hook напомнит получателю ответить с подсказкой. Реализация этого пункта ещё не начата.

Повторяющийся общий ETA «два часа» отозван как неподтверждённый. Контрольная точка чтения ChatGPT через установленный selector достигнута. Остаток оценивается по конкретным непройденным переходам: жизненный цикл ChatGPT, второй реальный аккаунт, Z.ai и общая пятисредовая приёмка.
