# Чистый пользовательский сценарий

Только поле полной цели и поле уточнения в панели автопилота. Обычное поле чата не использовать. После двух сохранений только наблюдать и обновлять состояние; не помогать агенту.

Это две части одной цели, и обе должны быть доведены до завершения. Работай исключительно в каталоге проекта этой сессии; не создавай другие файлы, не меняй посторонние данные и не выполняй внешних действий.
