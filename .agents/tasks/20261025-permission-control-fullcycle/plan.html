Цель и результат

Цель

Завершить все восемь оставшихся пользовательских сценариев Agent Herder, сохраняя принятые действия, нативные сессии и чужой WIP.

Что будет работать

Пользователь управляет доступными режимами и точными разрешениями через Herder/Notice Place, получает правдивые результаты доставки и очередей, видит preview до 8000 символов, вводит текст и голос без случайной отправки и ищет по каталогу с честным покрытием. Всё проверено на одном опубликованном выпуске.

Как проверим

  • Разрешения: точный native request → одна Notice Place карточка в изолированный test route → ответ → независимый native readback; unsupported показан честно.
  • ZCode: один stable queue-resume с expectedRevision → подтверждённый native результат без replay.
  • MiniMax: одна новая изолированная agent-to-agent доставка в idle session → точная receipt и ответ с actual provider/model.
  • Preview: установленный UI сохраняет и показывает 8000 символов без подмены токенами.
  • Composer/voice: реальные клавиши/click/long-press/Steer/Queue, MediaRecorder → настоящий same-origin Whisper → вставка текста без autosend.
  • Поиск: известное совпадение найдено на правильном host/harness, partial/unavailable явно отличаются от полного нуля.
  • OpenCode empty-success: terminal outcome виден без финального текста и без повторения accepted side effects.
  • Общий выпуск: один joined source/artifact, публичный SSO UI и независимые пользовательские проверки всех ветвей.

Это декларация плана. Статус задач сам по себе не подтверждает приёмку результата.
