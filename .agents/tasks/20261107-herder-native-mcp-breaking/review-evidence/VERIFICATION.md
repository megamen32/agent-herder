# Проверка нулевой ревизии v1

7 ноября 2026, после прямой коррекции владельца.

- Canonical `plan_cli.py check` подтвердил согласованность.
- validate_plan.py: в графе ровно 159 V-листьев, все queued/unassigned, <=60 минут; исторических и deferred — ноль, старая revisions history отсутствует в текущем plan.json.
- Все зависимости существуют, граф ацикличен; входы/листья/WORKPLAN согласованы.
- 5 прямых adapter lanes: Codex, OpenCode, ZCode, ChatGPT, Z.ai; 5 явных native uncertainty fields. Остальные среды только в NEXT-UPDATE, не в исполнимом графе.
- 6 расписаний для 1/2/4 исполнителей min/max проверены на dependency, slot и lane ограничения.
- Исходная ревизия 4 и полное независимое ревью до сокращения scope сохранены в history, SHA256 совпадают.
- Удаление лишнего выполнено только внутри этого плана по прямому разрешению; установленный LHC и чужой WIP не менялись.

Выполнялись проверки плановых артефактов, не продукта. Runtime/implementation/deployment и исполнители этой сессией не запускались. Следующий шаг принадлежит исходной сессии: принять handoff и запустить bounded Workers по V-графу.

Generated HTML может переписываться штатным LHC observer; это проекция тех же leaves. Архив сохранён побайтно, поэтому исторические пробелы/форматирование не исправляются. Отдельный расчёт ESTIMATES учитывает lane и продуктивные часы; автоматическая дата страницы не означает назначенный старт.

Для нулевой ревизии создана новая canonical publication identity, чтобы старые A/R записи не попадали даже в свёрнутую историю HTML. Предыдущая страница и локальные publication metadata сохранены в истории.
