# Agent Herder v1 — нулевая ревизия

[Чистая публичная страница v1](https://lhc.bezrabotnyi.com/agent-herder/plan-20261107-0201-32b478c1739c91878719ddcd/)

Прямое решение владельца 7 ноября 2026: первая версия поддерживает **Codex, OpenCode, ZCode, ChatGPT и Z.ai**. Прежние ревизии и все отложенные листья убраны из действующего графа; сохранены в архиве. Ограничение действует только для этого плана, глобальный LHC не менялся.

Рабочая программа: **V001–V159**, 159 листьев по 20–60 минут; нет исторических/deferred листьев. Исполнители пока не запускались. План передаётся вызвавшей Astra сессии для запуска реализации.

Результат v1: 14 общих инструментов, стандартные MCP Tasks/Skills/subscriptions, несколько независимых instances на одной ноде; восстановление self/creator/sender/worktrees после компакции; atomic owner claim по известному файловому маршруту без MCP. Полный цикл включает native proof, потребителей, миграцию, удаление legacy, установку Linux/macOS и независимую приёмку. UNKNOWN не пересылается, HumanStop и чужая история сохраняются.
