## Ответственность и сообщения

- Terra владеет core и четырьмя своими назначениями. Она не управляет шестью соседними сессиями. Astra распределяет стыки и получает вопросы/результаты от направлений.
- Shared Cargo/lib.rs wiring меняет один объявленный интегратор core. Каждый исполнитель присылает точный необходимый delta; произвольные параллельные изменения одного файла запрещены. Изолированный module commit можно завершить независимо, потом объединить wiring одной интеграцией.
- Координация не требует разрешения на каждый 15-минутный шаг. Исполнитель продолжает готовую цепочку до результата; сообщает только факт, меняющий следующий шаг другого: блокер, контракт, конфликт, завершённый артефакт.
- Квоты/доступность и conflicts проверяются при назначении. 10 — плановый общий пул исполнительской работы, не введённая квота CPU/RAM и не десять подчинённых Теры. В следующей волне свободные сессии получают consumers/миграцию/платформы через Astra; новые менеджерские слои не создаются.
- Независимые сессии начинают доступную работу сразу. Неподдерживаемый SDK/отсутствующий аккаунт блокирует точный путь; отсутствие ответа не ведёт к бесконечному polling или повторной внешней отправке.
- Владелец ранее потребовал консультации Теры с Astra не реже часа; существующий cadence сохраняется. Новые сессии сообщают вопросы сразу и результаты по завершении meaningful outcome; шестью новыми таймерами не дублировать этот механизм.
