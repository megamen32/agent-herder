# После версии 1

По прямому решению владельца следующие адаптеры **не входят в v1**:

- Claude;
- Qoder;
- Hermes;
- Fast Agent;
- MiniMax Code;
- отдельный общий Browser Chat endpoint.

Их прежние исследования/листья сохранены в history/astra-review-before-v1-zero. В рабочем графе v1 нет заданий со статусом deferred и нет скрытых зависимостей от этих адаптеров. Перед следующим обновлением заново подтвердить версии и native capabilities, затем создать отдельный актуальный план. Не запускать эти работы автоматически вместе с v1.

Секретарь в v1 использует обычный deliver к разрешённому ChatGPT target, без зависимости от общего Browser Chat adapter. Удаление legacy не удаляет нативные истории/аккаунты отложенных сред. Перед cutover сообщить потребителям, что в v1 эти среды не поддерживаются; не подменять их другим harness молча. Старые legacy endpoints при этом не сохраняются как совместимая прослойка.
