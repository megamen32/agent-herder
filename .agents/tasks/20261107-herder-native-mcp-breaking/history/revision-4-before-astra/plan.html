Цель и результат

Цель

Полная новая реализация Agent Herder на Rust с общим интерфейсом адаптеров; инфраструктура задаётся конфигурацией; каждый рабочий лист <=60 минут.

Как проверим

  • После установки точного артефакта новый MCP-клиент обнаруживает ровно 17 команд и Skills; два экземпляра Codex на одной ноде и удалённый harness создают независимые сессии, получают ровно свои сообщения, возвращают recent user+assistant и полный transcript. Неверный вызов исправляется по ответу без исходников. MCP Tasks/подписки переживают reconnect; UNKNOWN не повторяется; STOP сохраняется; старые имена не вызываются. Все поддерживаемые реальные harness и потребители проверены по матрице. Дополнительно A создаёт B, C пишет B; после compaction и рестарта B восстанавливает родство/корреспонденцию и отвечает C. Гонка checkout имеет одного победителя; offline peers не дают ложного одиночества. Выключенный daemon/MCP не мешает прочитать canonical JSON и атомарно занять свободную роль через независимый CLI; после рестарта один owner/fence.

Это декларация плана. Статус задач сам по себе не подтверждает приёмку результата.
