# Ограничение канонической проекции LHC

Найдено при финальной проверке 7 ноября 2026. Это дефект представления общего LHC renderer, не дефект исполняемого Agent Herder.

Наблюдение: в plan.html плитка «Усилие» показала 422 ч 35 мин при 219 действующих queued листьях с суммой 104,5–201,3 ч. Граф содержит ещё 168 исторических done/deferred записей. Автоматический slot forecast показал 32 ч 55 мин – 62 ч 10 мин, тогда как проверенный scheduler с единственным исполнителем на lane дал 34 ч 50 мин – 66 ч 15 мин. Автодата старта выводилась из события плана, хотя запуск реализации не назначен. Часть historical actual timing HTML может обогащаться observer без изменения leaf input; это не измерение этого ревью.

Принятая в разрешённом scope мера: current_progress предупреждает об агрегатах; ESTIMATES.md/forecast.json содержат отдельный расчёт только A-листьев и явные допущения; 11 connection leaves имеют estimate_unknown_reason до прохождения native gates. Исторические листья не удалены и не выданы за выполненные.

Граница ремонта: пользователь ограничил запись документами/графом этого плана и запретил менять установленный LHC. Поэтому общий renderer не изменён. Минимальное следующее действие у проекта LHC — воспроизвести на графе queued+deferred, исключить deferred из усилия будущей поставки, различать условный forecast/неизвестный старт и учитывать resource lane либо явно подписать её отсутствие. Эта заметка — сохранённое доказательство и точный blocker внешнего ремонта; сообщение другой сессии не отправлялось.

Публичная страница годится для статусов и зависимостей. Для бюджета/календаря использовать ESTIMATES.md; ни один forecast не является фактом запуска.
