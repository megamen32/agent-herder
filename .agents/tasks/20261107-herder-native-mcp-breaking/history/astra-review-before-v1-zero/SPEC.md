# Agent Herder: действующий план — ревизия 5 Astra

7 ноября 2026. Независимая критика и переработка плана завершены в документах; реализация, делегирование и deployment не запускались. Исходная [ревизия 4](history/revision-4-before-astra/SPEC.md) сохранена с [контрольными суммами](history/revision-4-before-astra/SHA256.json). history/rejected-r1 остаётся историей, не заданием.

После переписи агент одним понятным вызовом восстанавливает себя, создателя, отправителей и соседей по проекту; безопасно общается с несколькими instances на одной ноде; при отказе MCP занимает свободное владение через заранее известный canonical storage. Старый API и daemon удалены после migration/cutover; native histories, UNKNOWN receipts, HumanStop и чужой WIP сохранены.

Активная реализационная программа — A001–A219, все queued/unassigned. Прежние R001–R149 помечены заменёнными, не выполненными; требования сопоставлены в критике. Модель исполнителей не выбиралась и агенты не создавались; унаследованные служебные model fields графа не являются назначением.

Сумма bounded slices 104,5–201,3 инженерного часа условна при подтверждённых native/client контрактах. Это не обещание срока всей переписи: трудоёмкость отсутствующего native API или изменения внешнего клиента неизвестна до ранних gates. Число листьев не цель; меньше механизмов и проверяемые результаты важнее красивой малой цифры.
