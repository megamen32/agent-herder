## Проверка допустимости provider-aware исправления

Локальный `base_url` также может указывать на proxy к подписочному endpoint. В текущем `CodexAppServerAdapter` можно подключить произвольный Unix socket, для которого `CODEX_HOME` локального adapter не доказывает эффективную конфигурацию и network namespace владельца сокета; при bin transport текущий launcher в sandbox требует отсутствующий user systemd bus. `config/read` показывает эффективный конфиг, но сам по себе не доказывает конечного получателя запроса за proxy или источник bearer token. Поэтому сделать разрешённое исключение по одному config/URL без дополнительного доказательства нельзя: это нарушило бы прямое требование не ослаблять subscription guard.
